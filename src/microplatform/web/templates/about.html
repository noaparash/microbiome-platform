About

One place for the microbiome tools developed in Prof. Yoram Louzoun's lab at Bar-Ilan University.

Why this platform

The lab has published five complementary tools: for preprocessing, prediction, differential abundance, distances between samples, and microbiome–metabolome integration. Each has its own package and input conventions. This platform puts them behind one interface that checks your data, recommends the right tool, explains why, and returns publication-ready, reproducible results, while asking you for as little as possible.

Your data

Uploads and results are stored on the server that runs the platform, in a folder for each run, and are not sent anywhere else. For sensitive or clinical data you can run the same analyses on your own computer with the Python package (see Docs & API).
