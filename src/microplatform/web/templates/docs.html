Using the website

  1. Upload. Optionally pick your question on the home page; the upload box then says which files it needs. Drop the files: they are recognised automatically.
  2. Data check. See what was found. Errors say how to fix them; warnings (like a sample with unusual depth) do not block the analysis.
  3. Plan. A task is recommended, with the reasons. Choose another if you like, or add a missing labels file right there.
  4. Results. Summary, figures, the processed table and a reproducibility record. Each run has its own link; bookmark it to come back.

What you get

  • The processed table (CSV): one row per sample, one column per feature.
  • Every figure as PNG, SVG (editable text) and an interactive HTML that works offline, each with the CSV of the exact data plotted.
  • “Download everything”: one ZIP with a README, the record of every setting and version, the results, the figures and your input files.

Using Python

Install the package (a public release on PyPI is planned):

python -m pip install -e .

A whole analysis, without the website:

import microplatform as mp

view = mp.analyze("counts.csv", "labels.csv")
print(view.recommendation.reasons)
print(view.run.path)          # table, figures, record

Or step by step:

counts = mp.read_table("counts.csv")
profile = mp.profile_counts(counts)
print(profile.summary(), profile.issues)

result = mp.preprocess(counts)            # MIPMLP with the paper's settings
result.table.to_csv("processed.csv")
print(result.record())                    # every setting and version used
