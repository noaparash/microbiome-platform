What should my files look like?

Counts table: one row per sample and one column per bacterium. The first column holds sample IDs, and the last row is named taxonomy.

ID,       ASV1,          ASV2,          …
sample1,  120,           0,             …
sample2,  37,            5,             …
taxonomy, k__Bacteria;…, k__Bacteria;…, …

Labels (optional): sample IDs in the first column and the outcome in a column named Tag, for example sick/healthy or an age.

ID,      Tag
sample1, 1
sample2, 0

Metabolite table (optional, for linking bacteria to metabolites): sample IDs in the first column, the same as in the counts table, then one column per metabolite with the measured concentrations or intensities (not log-transformed; 0 means not detected). At least {{ min_metabolite_columns }} metabolite columns, and at least {{ min_paired }} samples that are also in the counts table.

ID,      Acetate, Butyrate, …
sample1, 5210.4,  830.2,    …
sample2, 4480.0,  0,        …
