Methods

The platform runs the lab's published tools, unchanged, behind one shared data pipeline.

How an analysis works

  1. Data check. Every upload is profiled: samples, taxa, taxonomy depth, sparsity, read depth and label type. Problems are reported with a fix; outliers are flagged.
  2. One shared representation. The counts are preprocessed once with MIPMLP, and every tool works from that same table, with the labels aligned to the same samples. Tools may vary only {{ allowed | join(" and ") | replace("_", " ") }}; everything else is identical.
  3. The right tool. Each task declares the inputs it needs, and the plan recommends a task and explains why.
  4. Faithful to the originals. Each tool runs the authors' own code, and every tool added to the platform comes with a reproduction test: on the authors' example data, the platform must give exactly the authors' result.
