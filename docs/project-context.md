# הקשר הפרויקט — מסמך מלא ומעודכן

מסמך הקשר מרכזי לפרויקט, לשמירה בתיקיית `docs/`. נועד שכל מי שעובד על הפרויקט — Claude Code, וכל צ'אט תכנון — יראה את התמונה המלאה: המטרה, הארכיטקטורה, מבנה האתר, דרישות הפרופסור, הכלים, ההחלטות, והסטטוס. עודכן: 20.10.2026.

## מי ומה
נועה, עובדת חדשה במעבדה של פרופ' יורם לוזון. ללא ניסיון קודם בתכנות. התפקיד: לכוון ולבדוק; Claude Code כותב את הקוד בפועל, בצעדים קטנים שמוצגים לאישור.

## המטרה
פלטפורמה אחת חכמה שמאחדת את חמשת כלי המיקרוביום של אושרית שטוסל (MIPMLP, iMic/gMic, miMic, GIMIC, LOCATE), ויודעת לבחור באיזה כלי להשתמש לפי השאלה והנתונים — ברמה מקצועית גבוהה מאוד.

## הארכיטקטורה (הרעיון)
ייצוג משותף אחד: כל הכלים מתחילים מ-MIPMLP ← עץ טקסונומי של log-frequencies, שמחושב **פעם אחת**. מעליו:
- **פרופיילינג אוטומטי** של הנתונים (תוויות? מטבוליטים? סדרת-זמן?).
- **נתב חכם** שבוחר כלי ומנמק.
- **ארבעה מנועים** שמתחברים זה לזה: iMic/gMic (ניבוי), miMic (מבחן סטטיסטי), GIMIC (מרחק/קיבוץ), LOCATE (מיקרוביום+מטבולום).
- **פלט מאוחד** + הסבר (XAI) + דוח לשחזור, על תשתית אחת (חבילת Python + Flask + Python 3.13).

## מבנה האתר (מהמצגת לפרופסור)
- **חמישה עמודים:** Home · New analysis · Example · Methods · Docs & API · About. האתר באנגלית.
- **ניתוח = אשף של 4 שלבים:** Upload (קובץ חובה אחד + בדיקה מיידית) ← Data check (פרופיל אוטומטי) ← Plan (המלצה עם נימוק; המשתמש רק מאשר) ← Results (תקציר, לשונית לכל כלי, דוח שחזור).
- **דף הבית:** כניסה לפי שאלה ("אילו חיידקים שונים בין קבוצות?"), לא לפי שם כלי.
- **עיקרון מנחה:** לבקש מהמשתמש כמה שפחות; האתר שכבה דקה מעל חבילת Python אחת.

## דרישות הפרופסור (20.10) — אושרו
1. **ריצות כבדות לא תלויות בדפדפן:** ריצה ברקע עם ID ייחודי + קישור-תוצאה; אימייל אופציונלי להתראה בסיום ושליחת/הורדת תוצאות. לא נדרש ל-MIPMLP הקל; חובה לפני iMic/LOCATE. (שליחת מייל דורשת SMTP — לסדר מול המעבדה.)
2. **שגיאות העלאה חדות:** לכל קלט שגוי (פורמט/עמודות) — לעצור עם הודעה ברורה: מה השגיאה, איך לתקן, והפורמט/דוגמה הצפויים.
3. **אופציה "רק עיבוד מקדים" (MIPMLP בלבד)** — למי שרוצה רק את הטבלה הנקייה.
4. **תוצאות גם כ-Figures וגם כ-CSV** להורדה/עריכה; כל גרף מגיע עם ה-CSV שמאחוריו, ואינטראקטיבי במידת האפשר.
5+6. **חבילה-תחילה, אתר דק:** כל הלוגיקה בחבילת Python אחת, מותקנת/ניתנת ל-import וציטוט; האתר שכבה דקה שרק מייבאת אותה, בלי לוגיקה בשכבת ה-web. החבילה היא המוצר הראשי (שומר נתונים קליניים אצל החוקר). תואם לארכיטקטורה שכבר נבנתה.

## החלטות מפתח
- **סטאק:** Python 3.13 + Flask; GitHub פרטי; pandas מוצמד ל-2.3 (pandas 3 שובר את MIPMLP).
- **עיבוד:** ריצה קנונית אחת + שינויים מוצהרים לכל כלי + caching; הגדרות המאמר (לא ברירות המחדל).
- **גרסה 1 = MIPMLP** קצה-לקצה, ואז miMic.
- **נרמול:** log של הספירות (לא relative) — המאמר הראה ש-log עדיף; ברירת מחדל עם מתג קל ל-relative. לאמת עם אושרית.
- **שימוש מול בנייה:** חבילות ה-pip הן הקוד של המחברים (מריצים, לא כותבים מחדש). גרסת מעבדה פנימית = שדרוג, לא תנאי לנכונות (חוץ מ-LOCATE).
- **דאטהסטים:** עדיין אין אמיתי — בינתיים קובצי דוגמה של המחברים; לבקש מאושרית.
